# Human or Not

Party drawing game. One person draws a prompt. An AI scribbles the same thing. Everyone else decides which drawing is human.

## Spaces

- [`dev`](https://github.com/speedywalt/human-or-not/tree/dev) is where changes go first.
- [`prod`](https://github.com/speedywalt/human-or-not/tree/prod) is the stable copy. Move a change here only when it is good enough to keep.
- `main` is the older Python server. It is not this version of the game.

## Run it

```bash
npm install
npm run dev
```
