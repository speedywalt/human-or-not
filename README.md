# Human or Not?

Multiplayer social deduction game — spot the human drawing and the AI player.

## How to play
1. Open the site
2. Create a room or join with a code
3. Host adds an AI player and starts the round
4. One player draws the prompt, AI generates an image
5. Discuss in chat and vote which image is human + who the AI is

## Local run
```
pip install -r requirements.txt
uvicorn main:app --reload
```
